🔑 API 키 설정

Claude 또는 GPT 키를 붙여넣고 [저장]을 누르면 바로 연결 테스트까지 합니다. 키가 없으면 가짜 응답 모드로 동작합니다. 키는 암호화되어 이 서버에만 저장됩니다.

Claude (Anthropic)

발급: console.anthropic.com → API Keys

GPT (OpenAI)

발급: platform.openai.com → API keys
