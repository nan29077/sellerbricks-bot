### 1-A 질문 (구현됨)
오늘/기간 주문 정리 · 방송별 주문 · 미입금 · 송장 미입력(발송 지연) · 취소 요청 · 정산·출금 · 많이 팔린 상품 · 상품·재고·구매링크 번호 · 주문 찾기(이름/닉네임/뒷4자리) · 도움말·연결·해제·상태

### 1-B 질문 (다음 차수)
다음 방송 일정·지난 방송 성과 · 오늘 문자 주문(MoMessage) 수 · 알림톡 잔여 크레딧 · 미답변 리뷰·안 읽은 상품 문의·신규 팬 · 샵 방문자(AnalyticsDaily) · 지난주 대비·시간대별 분석

## 다음 차수 (사용자 지시 후, 각 단계 보고 먼저)
1. GitHub 저장소 주소 받으면 첫 커밋·푸시 명령 안내
2. 셀러브릭스 브랜치 생성 후: 04 명세대로 내부 봇 API + "카카오 챗봇 연결" 화면 + 신규 테이블 2개 (설계 보고 → 승인 → 개발)
3. 봇에서 "실제 API" 전환 → 내부 테스트 → 셀러 5~10명 베타
4. 1-B 확장 도구
5. 스튜디오 배포 후: 스튜디오 API + 연결
6. 쓰기 작업(확인 버튼 필수), 아침 요약(알림톡/나에게 보내기)
7. 실서버 배포(EC2 + pm2 + HTTPS 도메인 예: bot.sellerbricks.co.kr), 콜백 신청 매뉴얼, PlayMCP 등록(원격 MCP 엔드포인트 + 사용자 인증 방식 설계)
