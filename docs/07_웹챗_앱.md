# 웹챗 · 안드로이드 앱 · 시작 페이지 (3차, 2026-11-13)

> 셀러는 **시작 페이지**에서 카카오 채널 / 웹챗 / 안드로이드 앱 중 골라 쓴다. 세 곳 모두 같은 대화 코어(`src/bot.ts`)와 같은 도구(`src/tools/`)를 쓴다.

## 1. 주소
| 주소 | 내용 |
|---|---|
| `/` | 시작 페이지 — 카카오 채팅 열기·채널 추가 / 웹챗 열기·링크 복사 / APK 내려받기 / QR(PC에서) |
| `/chat` | 웹챗 (모바일 우선, PC는 가운데 카드, 다크 모드, 홈 화면 추가 PWA) |
| `/download/app.apk` | 관리자 화면에서 올린 최신 APK (또는 외부 주소로 이동) |
| `/admin` | 관리자 화면 → **채널 · 앱** 메뉴에서 켜기/끄기, 카카오 채널 주소, APK 올리기 |

**기본 입구는 셀러브릭스 대시보드 맨 위 [AI 비서] 버튼**(셀러 역할만) — 누르면 1회용 코드로 이 웹챗에 자동 로그인된다(로그인 동기화, 04 명세 10장 — 셀러브릭스 쪽은 나중에 별도 브랜치에서 개발). 봇 시작 페이지는 링크 공유·점검 때 쓰는 보조 입구.

자동 로그인: `/chat?platform=SELLERBRICKS&code=123456` 으로 열면 코드 입력 없이 바로 로그인하고 주소창에서 코드를 지운다.

## 2. 로그인 (따로 가입 없음)
1. 셀러가 셀러브릭스(또는 스튜디오) 셀러 관리자 화면 → **AI 셀러 비서** 메뉴에서 6자리 코드를 받는다 (5분·1회용 — 카카오와 같은 코드, 04 명세 1번 API).
2. 웹챗·앱 첫 화면에 6자리를 입력 → 봇이 플랫폼에 코드를 확인하고 연결 토큰을 받는다.
3. 30일 세션 쿠키(HttpOnly·SameSite=Lax, DB에는 sha256만). 쓸수록 연장.
4. **같은 계정으로 다른 기기(PC·휴대폰·앱)에서 로그인하면 같은 대화 기록**을 본다. (계정 id 로 웹 사용자를 찾음)
5. 메뉴 → 연결 계정에서 두 번째 플랫폼(스튜디오) 추가·해제. 마지막 계정을 해제하면 로그아웃.

카카오 사용자와 웹 사용자는 처음에는 **채널별로 따로** 기록된다 (확정 권장안).

## 3. 채널별 차이 (`src/channels/profile.ts`)
| 채널 | 답변 길이 | 마크다운 | 긴 답변 | 1분 제한 |
|---|---|---|---|---|
| 카카오 | 600자 | 없음 | 900자 넘으면 "전체 보기" 페이지 | 10회 |
| 웹챗·앱 | 1500자 | 굵게·목록·표 | 화면에 그대로 | 20회 |
| 관리자 테스트 | 카카오/웹 모양 선택 | | | 없음 |
| MCP | 4000자 | | | 60회 |

웹·앱만의 기능: 표 그리기, 답변 복사, 👍/👎 아이콘(카카오의 "도움 됨/아쉬워요" 버튼 대신), 대화 기록 다시 보기(카드·버튼 포함 — `ChatLog.extraJson`), **결과물 다시 열기(30분 지난 링크는 같은 내용으로 새로 발급)**, 사진 첨부(긴 변 1600px로 줄여서 전송), 알림함(종 아이콘), 알림 종류별 켜기/끄기.

## 4. 보안
- 웹챗 API 의 모든 POST 는 `X-Requested-With: sbchat` 헤더가 있어야 함 (다른 사이트에서 위조 요청 차단, CORS 없음)
- 화면은 CSP `default-src 'self'`, `frame-ancestors 'none'` — 다른 사이트에 끼워 넣기(iframe) 불가
- 로그인 시도 1분 10회 제한, 셀러 차단 시 모든 세션·MCP 토큰 즉시 끊김
- 화면에 그리는 AI 답변은 모두 글자로 바꾼 뒤(escape) 굵게·목록·표만 다시 그림

## 5. 안드로이드 앱 (Capacitor 8)
웹챗을 그대로 띄우는 얇은 껍데기 — **화면·기능을 고쳐도 앱을 다시 배포할 필요가 거의 없다.** 앱은 User-Agent 끝에 `SellerbricksBotApp/1.0` 을 붙여 서버가 "앱" 채널로 구분한다. 뒤로 가기 버튼: 시트 닫기 → 이전 페이지 → 앱 종료.

### 처음 준비 (사용자 PC, 한 번만)
1. **Node.js 22 이상** (Capacitor 8 요구)
2. **Android Studio** 설치 → 처음 실행해서 SDK 설치 마법사 끝까지 (Java는 Android Studio에 포함)

### 만들기
1. `.env` 에 휴대폰이 접속할 서버 주소를 넣는다
   - 배포 후: `APP_SERVER_URL=https://bot.sellerbricks.co.kr`
   - PC에서 시험: `APP_SERVER_URL=http://192.168.0.10:3071` (PC 내부 IP, 같은 와이파이) / 에뮬레이터는 `http://10.0.2.2:3071`
   - 없으면 `PUBLIC_BASE_URL` 을 쓴다 (localhost 면 경고)
2. 폴더 `E:\프로젝트\sellerbricks-bot` 에서 **`5_build_apk.bat`** 실행 (처음엔 몇 분 걸림)
3. 결과: `data\apk-build\sellerbricks-ai.apk`
4. 관리자 화면 → 채널 · 앱 → **APK 올리기**(버전 입력) → "안드로이드 앱" 켜기 → 시작 페이지에 [APK 내려받기] 표시

지금은 **디버그 서명 APK**(베타 배포용). 플레이스토어 등록 때는 서명 키(keystore)로 release 빌드가 필요하다 — 그때 별도 안내.
앱 아이콘·스플래시는 `app-android/resources/` 의 그림으로 자동 생성된다.

### 셀러 설치 안내 (시작 페이지에도 있음)
휴대폰에서 [APK 내려받기] → 경고가 나오면 [다운로드] → 파일 열기 → "출처를 알 수 없는 앱" 이번만 허용 → 설치 → 6자리 코드로 로그인

## 6. 아이폰
APK 는 설치할 수 없으므로 웹챗을 Safari로 열어 **공유 → 홈 화면에 추가**. (시작 페이지·웹챗 메뉴에 안내)

## 7. 관리자 화면 (채널 · 앱)
- 카카오 채널 / 웹챗 / 안드로이드 앱 각각 켜기·끄기 — 끄면 시작 페이지에서 버튼이 사라지고, 웹챗은 "잠시 쉬고 있어요", 카카오는 웹챗 주소로 안내
- 카카오 채널 주소 (`http://pf.kakao.com/_xxxx`) → 채팅 바로가기(`/chat`)·채널 추가(`/friend`) 자동 생성
- APK 올리기(200MB 이하, ZIP 형식 검사, 바로 전 버전 1개 보관) 또는 외부 주소(https)
- 시작 페이지 안내 문구(점검 공지 등)
- 웹챗·앱 로그인 세션 목록·강제 로그아웃
