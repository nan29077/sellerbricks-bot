# 카카오 채널 · 챗봇 설정 매뉴얼 (2026-11-13)

> 카카오 관리자센터 화면의 메뉴 이름은 바뀔 수 있다. 막히면 화면을 캡처해서 Claude 에게 보여 줄 것.
> 서버가 **공개 HTTPS 주소로 배포된 뒤**에 진행한다 (`docs/08_배포가이드.md`).

## 1. 셀러용 카카오톡 채널 만들기 (결정: 구매자용과 분리)
1. 카카오톡 채널 관리자센터(center-pf.kakao.com) → 새 채널 만들기 (예: "셀러브릭스 셀러센터")
2. 채널 공개·검색 허용, 프로필 사진은 `public/icon-512.png` 사용 가능
3. **채널 URL** 확인 (`http://pf.kakao.com/_xxxx`) → 봇 관리자 화면 → 채널 · 앱 → **카카오 채널 주소**에 입력
   → 시작 페이지의 [카카오톡 채팅 열기]·[채널 추가] 버튼이 이 주소로 연결된다.

## 2. 챗봇 만들기 (카카오 i 오픈빌더)
1. 챗봇 관리자센터(chatbot.kakao.com) → 봇 만들기 → 카카오톡 챗봇
2. 설정 → 카카오톡 채널 연결 → 1번에서 만든 채널 선택

## 3. 스킬 등록
1. 봇 관리자 화면 → 서비스 연결 → **카카오 스킬 주소** 복사 (`https://bot.도메인/kakao/skill/비밀경로`)
2. 오픈빌더 → 스킬 → 생성 → URL 에 붙여넣기 → 저장
3. 비밀 경로는 외부에 알리지 말 것 (요청 서명이 없어서 주소가 곧 열쇠)

## 4. 블록 연결
1. 시나리오 → **폴백 블록** → 파라미터 설정/봇 응답에서 **스킬데이터 사용** → 3번 스킬 선택 → 저장
   (모든 말이 스킬로 가서 AI 가 답한다)
2. 웰컴 블록도 스킬데이터 사용으로 바꾸면 첫 인사가 봇 도움말로 나온다 (선택)

## 5. 사진 받기 (사진으로 상품 등록)
1. 폴백 블록(또는 상품 등록용 블록)의 파라미터에 **보안 이미지(sys.plugin.secureimage)** 추가 — 필수 아님(선택)으로
2. 봇은 블록 파라미터에서 이미지 주소를 찾아 받자마자 저장한다 (`src/kakao/routes.ts` extractImages)

## 6. AI 챗봇 콜백 신청 (긴 답변용)
- 카카오는 스킬이 **5초 안에** 답해야 한다. 리포트·글쓰기처럼 오래 걸리는 답은 콜백이 필요하다.
- 오픈빌더 → 설정 → **AI 챗봇 관리** → 콜백 사용 신청 (심사 후 승인)
- 승인 전: 4초 안에 끝나면 바로 답, 넘으면 "[결과 보기]를 눌러 주세요" 로 받는다 (이미 구현)
- 승인 후: 폴백 블록에서 **콜백 사용** 켜기 → 봇이 자동으로 `useCallback` 으로 답하고 끝나면 결과를 보낸다 (이미 구현)

## 7. 배포
오픈빌더 → 배포 → 배포하기. 채널 채팅방에서 "도움말" → "연결 123456" → "오늘 주문 정리해줘" 순서로 확인.

## 8. 문제 해결
| 증상 | 확인 |
|---|---|
| 아무 답이 없음 | 스킬 URL 비밀 경로 오타, 서버 `/health`, 관리자 화면 → 채널 · 앱에서 카카오가 켜져 있는지 |
| "잠시 쉬고 있어요" | 관리자 화면에서 카카오 채널이 꺼져 있음 |
| 사진을 못 받음 | 블록에 보안 이미지 파라미터가 있는지 |
| 긴 답이 잘림 | 900자 넘으면 "전체 보기" 버튼으로 넘어가는 것이 정상 |
