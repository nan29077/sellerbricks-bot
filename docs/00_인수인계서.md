## 1. 이 프로젝트가 무엇인가
- **셀러브릭스 + 셀러브릭스 스튜디오 공용 "AI 셀러 비서" 서버.** 봇은 두 플랫폼과 **따로 운영**한다 (스튜디오도 같은 봇에 붙이기 위해).
- 셀러가 쓰는 입구 3가지 — **시작 페이지(`/`)에서 골라 씀**
  1. **카카오 채널** (오픈빌더 스킬) — 채팅방에서 "오늘 주문 정리해줘"
  2. **웹챗** (`/chat`) — 링크로 접속, 6자리 코드 로그인, 홈 화면 추가(PWA)
  3. **안드로이드 앱(APK)** — 웹챗을 감싼 Capacitor 앱, 시작 페이지에서 내려받기 (아이폰은 웹챗 홈 화면 추가)
- 세 입구 모두 같은 대화 코어(`src/bot.ts`) + 같은 도구(`src/tools/`, MCP 형식)를 쓴다.
- **외부 AI 연동(MCP)**: `/mcp` — 셀러가 자기 Claude·ChatGPT 에서 도구를 쓰게 함 (셀러별 토큰). OAuth(PlayMCP 등록용)는 다음 단계.

## 4. 작업 규칙 (반드시 지킬 것)
1. **셀러브릭스 저장소 변경은 별도 브랜치에만.** (`feature/kakao-chatbot` 등 — 이름은 착수 시 사용자 확인) **main 병합 금지.** 스튜디오도 마찬가지.
2. sellerbricks-bot 저장소는 main 브랜치.
3. **Git 명령은 Claude가 device_bash로 직접 실행하지 않는다.** 폴더 위치를 명시한 명령을 한 줄씩 사용자에게 제공하거나 `4_git_push.bat`.
4. `.gitignore`에 `.env*`, `node_modules`, `dist`, `data` — 비밀키·DB·APK 커밋 금지.
5. 사용자는 개발 초보 — 명령은 한 줄씩, 실행 폴더를 항상 명시.
6. 직접 만드는 `.bat` 파일은 **영문(ASCII) 전용**.
7. device_bash에서는 파일 삭제 불가 — 지울 파일은 사용자에게 요청.
8. device_bash 는 사용자 PC 의 **Linux VM**. `npm install` 을 거기서 하지 말 것 → 코드는 Claude 작업 공간에서 만들고 점검한 뒤 파일만 이 폴더로 복사. 설치·실행은 사용자가 Windows 에서 `0_preview.bat`.
9. 관리자 화면 디자인은 다른 세션이 맡을 수 있음 — `public/admin.*` 를 크게 바꿀 땐 06 메모 확인. 3차 기능은 `public/admin-ext.js` 에 따로 있음.
10. **도구는 채널을 모르게** (MCP 재사용 규칙, 10 문서 4장).

### ⚠️ 셀러브릭스 운영 DB 주의
- `app\app\.env` 의 DATABASE_URL 은 **운영 RDS를 직접 가리킴.** 로컬 Prisma 명령이 운영에 그대로 반영됨.
- 금지: `prisma migrate reset`, `db push --force-reset`, `db push --accept-data-loss`, 옛 `__db_push.bat`.
- 절차: pull → `npx prisma migrate diff --from-schema-datasource prisma/schema.prisma --to-schema-datamodel prisma/schema.prisma --script` 로 DROP 없는지 확인 → `npx prisma db push --skip-generate` → `npx prisma generate`.
- 챗봇 연동은 **신규 테이블 추가만**, 기존 테이블 변경 없음 원칙.
