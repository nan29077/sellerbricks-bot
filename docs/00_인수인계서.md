## 1. 이 프로젝트가 무엇인가
- **셀러브릭스 + 셀러브릭스 스튜디오 공용 카카오 채널 챗봇·MCP 서버.**
- 셀러가 카카오톡 채널 챗봇에 "오늘 주문 정리해줘", "수요일 화장품 방송 가능한 스튜디오 추천해줘" 같은 말을 보내면 → 이 서버가 AI + 도구 호출로 두 플랫폼 데이터를 조회해 카톡으로 답한다.
- 도구는 **MCP 형식**으로 만든다 → 나중에 카카오 PlayMCP 등록·카카오툴즈 제휴에 재사용.

## 2. 현재 상태 (2026-11-13 갱신)
- **1차 개발(1~7단계) + 2-1차 고도화 완료.** 범용 조회·결과물(리포트/CSV/PDF)·문구 작성·FAQ·대화 품질·사진 상품 등록. 가짜 데이터 + 가짜 응답 모드로 전체 동작, 자체 점검 95개 통과. 다음은 2-2차(03 문서).
- 포트 **3071**, 봇 DB **SQLite**, 관리자 화면 `/admin` (API 키 카드 맨 위, Claude/GPT 선택).
- 셀러브릭스 실제 연동 전 — 셀러브릭스 쪽 API 는 사용자가 브랜치를 만든 뒤 `04_플랫폼API명세.md` 대로 개발.
- GitHub: https://github.com/nan29077/sellerbricks-bot (main 브랜치 1개). 커밋·푸시는 `4_git_push.bat`(사용자가 실행). 병렬 작업 중에는 끝난 뒤 한꺼번에 커밋.
- 사용자는 매 단계 **"개발하지 말고 보고부터"** 를 원함 → 작업 전 계획을 보고하고 승인받은 뒤 진행.

## 4. 작업 규칙 (반드시 지킬 것)
1. **셀러브릭스 저장소 변경은 별도 브랜치에만.** MCP/챗봇 연동용 변경(챗봇 연결 화면, 내부 봇 API)은 `feature/kakao-chatbot` 브랜치(이름은 착수 시 사용자 확인)에 커밋·푸시. **main 병합 금지** — 사용자가 명시적으로 지시할 때만.
2. **sellerbricks-bot 저장소**: GitHub 주소는 사용자가 생성해서 전달 예정. **비공개(Private), main 브랜치로 진행.**
3. **Git 명령은 Claude가 device_bash로 직접 실행하지 않는다.** (과거 index.lock 잔류 문제, 작업 환경에서 GitHub 접속 차단) → 폴더 위치를 명시한 명령을 **한 줄씩** 사용자에게 제공. 사용자가 직접 실행하거나 Codex가 커밋·푸시하기도 함.
4. `.gitignore`에 `.env*`, `node_modules`, 빌드 산출물 포함 — 비밀키 커밋 금지.
5. 사용자는 개발 초보 — 명령은 한 줄씩, 실행 폴더를 항상 명시.
6. 직접 만드는 `.bat` 파일은 **영문(ASCII) 전용** (cmd가 한글 UTF-8을 깨뜨림).
7. device_bash에서는 파일 삭제 불가 — 지울 파일은 사용자에게 요청.
8. device_bash 는 사용자 PC 의 **Linux VM** 이다(Windows 아님). `npm install` 을 거기서 하면 Linux용 Prisma 엔진이 깔리므로 **설치·실행은 사용자가 Windows 에서 `1_setup.bat`** 으로 한다. 코드는 Claude 작업 공간에서 만들고 점검한 뒤 파일만 이 폴더로 복사.

### ⚠️ 셀러브릭스 운영 DB 주의
- `app\app\.env` 의 DATABASE_URL 은 **운영 RDS를 직접 가리킴.** 로컬 Prisma 명령이 운영에 그대로 반영됨.
- 금지: `prisma migrate reset`, `db push --force-reset`, `db push --accept-data-loss`, 옛 `__db_push.bat`.
- 절차: pull → `npx prisma migrate diff --from-schema-datasource prisma/schema.prisma --to-schema-datamodel prisma/schema.prisma --script` 로 DROP 없는지 확인 → `npx prisma db push --skip-generate` → `npx prisma generate`.
- 챗봇 연동은 **신규 테이블 추가만**, 기존 테이블 변경 없음 원칙.
