# 셀러브릭스 연동 가이드 — 순서와 Claude 지시 문장 (2026-11-13)

> 나중에 셀러브릭스와 실제로 연결할 때 이 문서 순서대로 진행한다. 스토리지 마켓(옛 셀러브릭스 스튜디오)은 셀러브릭스 연동이 끝난 뒤 **같은 방식**으로 진행(그때 별도 안내).
> 지금 봇은 셀러브릭스 없이 가짜 데이터로 완전히 동작한다. 셀러브릭스 저장소는 아직 아무것도 바뀌지 않았다.

## 완성되면 이렇게 동작한다
- **셀러**: 셀러브릭스 로그인 → 대시보드 맨 위 **[AI 비서]** → 새 탭에 웹챗이 **로그인된 상태로** 열림 → 바로 질문. 웹챗 메뉴에서 APK 받기 · 카카오 채널로 이용도 선택
- **최고관리자**: 셀러브릭스 좌측 메뉴 **"AI 셀러 비서 관리"** → 봇 관리자 화면이 자동 로그인으로 열림 (관리 기능은 봇 한 곳)
- **데이터**: 봇이 셀러브릭스 내부 봇 API(서명 키)로 그 셀러의 주문·정산·상품만 조회. 봇은 셀러브릭스 DB 에 직접 붙지 않는다

## 순서

### 1단계 — 봇 최신 상태 커밋 (직접)
`E:\프로젝트\sellerbricks-bot` 에서 `0_preview.bat` 로 확인 → `4_git_push.bat`

### 2단계 — 셀러브릭스 작업 브랜치 만들기 (직접, 한 줄씩)
```
cd /d "E:\프로젝트\sellerbricks\app"
git checkout main
git pull
git checkout -b feature/ai-assistant
```
(브랜치 이름은 바꿔도 됨. **main 에 직접 작업하지 않는다**)

### 3단계 — Claude 에게 설계 요청 (이 프로젝트 채팅에 붙여넣기)
```
셀러브릭스에 feature/ai-assistant 브랜치를 만들었어.
sellerbricks-bot 의 docs/11_셀러브릭스_연동가이드.md 와 docs/04_플랫폼API명세.md(3·4·7·8·10장)대로
셀러브릭스 AI 비서 연동 설계부터 보고해줘. 개발은 하지 말고 보고부터.
범위: ① 대시보드 상단 [AI 비서] 버튼(셀러만) + 웹챗 자동 로그인 코드 발급 API
② 최고관리자 좌측 메뉴 "AI 셀러 비서 관리"(봇 관리자 자동 로그인)
③ 계정 연결 테이블 2개(BotLinkCode·BotLink) + 내부 봇 API(/api/bot/v1/...)
운영 DB 는 신규 테이블 추가만, 기존 테이블 변경 금지.
```
→ Claude 가 셀러브릭스 코드를 읽고 버튼 위치·테이블·API 목록·화면을 보고 → **승인**

### 4단계 — 개발 지시
```
설계대로 셀러브릭스 feature/ai-assistant 브랜치에서 개발 진행해줘.
봇 쪽에 필요한 작은 변경(관리자 자동 로그인, 셀러브릭스로 돌아가기 링크)도 함께 해줘.
끝나면 운영 DB 반영 명령은 실행하지 말고 순서대로 안내해줘.
```
Claude 가 하는 일
| 어디 | 무엇 |
|---|---|
| 셀러브릭스 | [AI 비서] 버튼(셀러 역할만) · 웹챗 코드 발급 API · "AI 셀러 비서 관리" 메뉴(최고관리자만) · BotLinkCode/BotLink 테이블 · 내부 봇 API 22개(04 명세 4·7·8장, 기존 정산·상품 코드 재사용) · 연결된 기기 목록/해제 화면(선택) |
| 봇 | 관리자 자동 로그인(`/admin/sso`) · 셀러브릭스 안에서 열기 허용 설정 · 웹챗 "셀러브릭스로 돌아가기" 링크 · 자체 점검 추가 |

### 5단계 — 운영 DB 에 새 테이블 반영 (직접, Claude 가 한 줄씩 안내)
⚠️ 셀러브릭스 `app\app\.env` 는 **운영 RDS 를 직접** 가리킨다.
1. `cd /d "E:\프로젝트\sellerbricks\app\app"`
2. 바뀌는 내용 미리보기 — **DROP 이 하나도 없는지** 확인
   `npx prisma migrate diff --from-schema-datasource prisma/schema.prisma --to-schema-datamodel prisma/schema.prisma --script`
3. DROP 없으면 `npx prisma db push --skip-generate` → `npx prisma generate`
- 절대 금지: `migrate reset`, `db push --force-reset`, `--accept-data-loss`, 옛 `__db_push.bat`
- 이상한 내용이 보이면 실행하지 말고 화면을 Claude 에게 보여 줄 것

### 6단계 — 두 서버 연결 설정 (직접)
1. 긴 랜덤 **서명 키** 하나 만들기 (Claude 에게 "서명 키 만들어줘" 하면 됨)
2. 같은 값을 두 곳에
   - 셀러브릭스 `.env`: `BOT_API_SIGNING_KEY=…`, `BOT_PUBLIC_URL=http://localhost:3071`(배포 후 `https://bot.도메인`)
   - 봇 관리자 화면 → 서비스 연결 → 셀러브릭스 **"실제 API"** + API 주소(로컬 `http://localhost:3002`) + 서명 키 → 저장

### 7단계 — 내 PC 에서 함께 시험
1. 셀러브릭스 개발 서버(3002)와 봇(`0_preview.bat`, 3071) 둘 다 켜기
2. 셀러 계정으로 셀러브릭스 로그인 → **[AI 비서]** → 웹챗이 자동 로그인되는지
3. "오늘 주문 정리해줘", "입금 안 된 주문", "이번 달 정산 얼마야?" → **셀러브릭스 관리자 화면 숫자와 맞는지** 확인
4. 최고관리자로 로그인 → "AI 셀러 비서 관리" → 봇 관리자 화면이 열리는지
5. 이상한 점은 화면을 찍어 Claude 에게 → 수정

### 8단계 — 배포
1. 봇 실서버 배포 (도메인·HTTPS — `08_배포가이드.md`), 운영 `.env` 의 주소·서명 키 교체
2. 셀러브릭스는 **직접 지시할 때만** main 병합 → 기존 배포 방식으로 배포
3. 카카오 채널·APK 는 필요할 때 연다 (`09_카카오설정매뉴얼.md`, `07_웹챗_앱.md`)

### 9단계 — 베타
셀러 5~10명에게 먼저 열기 → 봇 관리자 화면의 품질 점검(아쉬워요·숫자 경고)으로 개선 → 전체 오픈
