# 실행·테스트 방법 (Windows)

## 준비물
- **Node.js 20 이상** (https://nodejs.org → LTS). 확인: 명령 프롬프트에서 `node -v`

## 처음 한 번
1. 탐색기에서 `E:\프로젝트\sellerbricks-bot` 열기
2. **`1_setup.bat`** 더블클릭 → 패키지 설치 + `.env` 생성 + 로컬 DB(`data\bot.db`) 생성
3. `.env` 를 메모장으로 열어 `ADMIN_PASSWORD=admin1234` 를 원하는 비밀번호로 바꾸고 저장

## 서버 켜기
1. **`2_start_dev.bat`** 더블클릭 (끄기: 창에서 Ctrl+C)
2. 브라우저에서 **http://localhost:3071/admin** → 비밀번호 로그인

## 관리자 화면에서 테스트
1. 맨 위 **🔑 API 키 설정** — 지금은 비워 둬도 됨(가짜 응답 모드). 키가 생기면 붙여넣고 [저장] → 자동 연결 테스트
2. **🧠 사용할 AI 선택** — Claude / GPT / 가짜 응답 중 선택 후 [AI 설정 저장]
3. **💬 테스트 채팅** — 오른쪽 "가짜 셀러 연결 코드"에서 셀러 고르고 [코드 발급] → [채팅으로 "연결 …" 보내기] → 빠른 질문 버튼 눌러 보기
4. **📜 최근 대화 로그** — 어떤 AI·도구가 쓰였는지, 오류가 있었는지 확인

## 자체 점검
**`3_selftest.bat`** — 별도 테스트 DB 로 46개 항목 점검. 마지막 줄 `결과: N 통과 / 0 실패` 확인.

## 명령으로 실행하고 싶을 때 (폴더: `E:\프로젝트\sellerbricks-bot`)
```
cd /d "E:\프로젝트\sellerbricks-bot"
npm install
npx prisma db push --skip-generate
npm run dev
```

## 자주 생기는 문제
| 증상 | 해결 |
|---|---|
| `node` 를 찾을 수 없음 | Node.js 설치 후 창을 새로 열기 |
| 3071 포트 사용 중 | 이미 켜진 서버 창 닫기, 또는 `.env` 의 `PORT` 변경 |
| 비밀번호 바꿨는데 안 됨 | 서버 창을 껐다 다시 `2_start_dev.bat` |
| 저장한 API 키가 "미입력"으로 보임 | `data\app-secret.txt` 또는 `.env` 의 `APP_SECRET` 이 바뀜 → 키 다시 입력 |
| prisma 오류(한글 경로 관련) | 오류 메시지를 그대로 Claude 에게 전달 |

## 카카오와 실제 연결 (나중에)
카카오는 **공개 HTTPS 주소**로만 스킬 서버를 부른다. 실서버 배포(또는 임시 터널) 후 오픈빌더 스킬 URL 에 `https://도메인` + 관리자 화면의 **📮 카카오 스킬 주소** 경로를 넣는다. 콜백 승인 전에도 4초 안에 끝나는 답(가짜 응답 모드 등)은 바로 나간다. 자세한 신청·설정 매뉴얼은 배포 단계에서 제공.
