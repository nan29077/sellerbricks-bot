# 실행·테스트 방법 (Windows)

## 준비물
- **Node.js 20 이상** (https://nodejs.org → LTS). 확인: 명령 프롬프트에서 `node -v`

## 처음 한 번
1. 탐색기에서 `E:\프로젝트\sellerbricks-bot` 열기
2. **`1_setup.bat`** 더블클릭 → 패키지 설치 + `.env` 생성 + 로컬 DB(`data\bot.db`) 생성
3. `.env` 를 메모장으로 열어 `ADMIN_PASSWORD=admin1234` 를 원하는 비밀번호로 바꾸고 저장

## 서버 켜기
1. **`0_preview.bat`**(또는 `2_start_dev.bat`) 더블클릭 (끄기: 창에서 Ctrl+C). 새 패키지가 있으면 자동 설치, DB 구조도 자동으로 맞춤
2. 주소
   - 시작 페이지: **http://localhost:3071/** (카카오·웹챗·앱 선택)
   - 웹챗: **http://localhost:3071/chat**
   - 관리자: **http://localhost:3071/admin** → 비밀번호 로그인

## 관리자 화면에서 테스트
1. **API 키 설정**에서 키를 입력하고 [저장]을 누르면 연결을 확인합니다. 키가 없어도 기본 응답 모드로 테스트할 수 있습니다.
2. **사용할 AI 선택**에서 Claude, GPT, 기본 응답 중 하나를 골라 [AI 설정 저장]을 누릅니다.
3. 화면 하단의 **테스트 채팅**에서 샘플 셀러를 고른 뒤 [코드 발급], [연결 코드 보내기]를 차례로 누릅니다. 연결되면 빠른 질문을 누르거나 메시지를 직접 보내세요.
4. **최근 대화 로그**에서 사용한 AI와 도구, 오류를 확인할 수 있습니다.

## 2-1차 기능 시험 (테스트 채팅)
- 자유 조회: "이번 달 카드 주문 일별로", "5만원 이상 주문", "지난달 상품별 판매"
- 여러 개·이어 묻기: "입금 안 된 주문이랑 송장 안 넣은 주문" → "어제는?" → "그중 카드만"
- 결과물: "이번 달 매출 리포트 만들어줘", "주문 목록 엑셀로" → 버튼으로 결과 페이지 열기 → CSV 받기 / PDF 저장
- 문구: "3번 상품 방송 대본 써줘", "리뷰 답변 써줘 배송이 늦어요"
- FAQ: "정산 언제 들어와요?", "카드 주문서 취소는 어떻게 해?" (FAQ 관리에서 수정 가능)
- 상품 등록: [사진 첨부] + "간편 상품 등록해줘 32000원 20개" → 상품명 입력(기본 응답 모드) → 카드 버튼 → [판매 중지]
- 설정: "송장 지연 기준 3일로 해줘"

## 3차 기능 시험 (웹챗·앱·스튜디오·알림·MCP)
1. **웹챗**: 관리자 화면 테스트 채팅 → [코드 발급] (6자리 복사) → 새 창에서 http://localhost:3071/chat → 셀러브릭스 → 코드 입력 → 질문
   - 휴대폰으로 보려면 같은 와이파이에서 `http://PC내부IP:3071/chat` (예: 192.168.0.10)
2. **스튜디오**: 관리자 → 서비스 연결 → 셀러브릭스 스튜디오 "샘플 데이터" 저장 → 테스트 채팅 샘플 셀러 목록의 "(스튜디오)" 로 코드 발급 → 웹챗 메뉴 → 연결 계정 → 스튜디오 추가 → "수요일 화장품 방송 가능한 스튜디오 추천해줘", "내 스튜디오 예약"
3. **채널 · 앱**: 카카오 채널 주소 입력, 채널 켜기/끄기 → 시작 페이지 확인. APK 는 `5_build_apk.bat` (docs/07)
4. **알림**: 운영 · 알림 → 알림 켜기 → [지금 한 번 실행] → 웹챗 종 아이콘
5. **MCP**: 외부 AI(MCP) → 켜기 → 토큰 발급 → docs/10 의 curl 로 시험
6. 테스트 채팅 "답변 모양"을 웹챗·앱으로 바꾸면 웹용 답변(긴 답·표)을 미리 볼 수 있음

## 자체 점검
**`3_selftest.bat`**를 실행하면 별도 테스트 DB로 점검합니다. 마지막 줄의 `결과: N 통과 / 0 실패`를 확인하세요.

## 명령으로 실행하고 싶을 때 (폴더: `E:\프로젝트\sellerbricks-bot`)
```
cd /d "E:\프로젝트\sellerbricks-bot"
npm install
npx prisma db push --skip-generate
npm run dev
```

## 자주 생기는 문제
| 증상 | 해결 |
|---|---|
| `node` 를 찾을 수 없음 | Node.js 설치 후 창을 새로 열기 |
| 3071 포트 사용 중 | 이미 켜진 서버 창 닫기, 또는 `.env` 의 `PORT` 변경 |
| 비밀번호 바꿨는데 안 됨 | 서버 창을 껐다 다시 `2_start_dev.bat` |
| 저장한 API 키가 "미입력"으로 보임 | `data\app-secret.txt` 또는 `.env` 의 `APP_SECRET` 이 바뀜 → 키 다시 입력 |
| prisma 오류(한글 경로 관련) | 오류 메시지를 그대로 Claude 에게 전달 |

## 카카오와 실제 연결

서버를 공개 HTTPS로 배포한 뒤 `PUBLIC_BASE_URL`에 해당 주소를 설정하세요. 관리자 화면의 **카카오 스킬 주소**에서 전체 URL을 복사해 챗봇 관리자센터의 스킬 URL에 등록합니다. 스킬을 연결한 블록에 메시지를 보내 응답을 확인하세요. 콜백이 꺼져 있어도 4초 안에 처리한 답변은 바로 돌아오며, 더 오래 걸린 답변은 [결과 보기]로 받을 수 있습니다.
