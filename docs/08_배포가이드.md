# 배포 가이드 (2-2차 ⑨, 2026-11-13)

> 실서버 위치·도메인은 아직 사용자 결정 전. 아래는 **기존 EC2 + pm2 + nginx + HTTPS** 기준 예시 (`bot.sellerbricks.co.kr`).

## 1. 배포 전 체크리스트
| 항목 | 할 일 |
|---|---|
| 관리자 비밀번호 | `.env` 의 `ADMIN_PASSWORD` 변경, 또는 관리자 화면 → 운영 · 알림 → 비밀번호 변경 |
| APP_SECRET | `.env` 에 긴 랜덤값 고정 (잃어버리면 저장한 API 키·연결 토큰을 다시 넣어야 함) |
| PUBLIC_BASE_URL | `https://bot.sellerbricks.co.kr` (결과 링크·QR·카카오 스킬 주소에 쓰임) |
| KAKAO_SKILL_SECRET | 비워 두면 자동 생성 (관리자 화면에서 확인) |
| DB | 지금은 SQLite (`data/bot.db`). 운영 DB 종류는 결정 대기 — Prisma `provider` 와 `DATABASE_URL` 만 바꾸고 `db push` |
| 개인정보 | 해외 LLM 사용 → 개인정보처리방침에 처리위탁·국외이전 고지 (AI 에는 가린 이름·뒷4자리만 전달) |
| **Fastify 버전** | `npm audit` 에 fastify 4.x 보안 경고가 있음 → **운영 전 fastify 5 로 올리기**(별도 작업, 자체 점검으로 확인) |
| 셀러브릭스 API | 관리자 화면 → 서비스 연결 → 셀러브릭스 "실제 API" + 주소 + 서명 키 |

## 2. 서버 설치 (EC2, Ubuntu 예시)
```bash
# Node.js 22 이상, pm2
cd /srv && git clone https://github.com/nan29077/sellerbricks-bot.git && cd sellerbricks-bot
cp .env.example .env   # 값 채우기
npm ci
npm run build          # dist/ 생성
npx prisma db push --skip-generate
pm2 start ecosystem.config.cjs
pm2 save && pm2 startup
```
업데이트: `git pull && npm ci && npm run build && pm2 restart sellerbricks-bot`

## 3. nginx (HTTPS)
```nginx
server {
  listen 443 ssl http2;
  server_name bot.sellerbricks.co.kr;
  # ssl_certificate … (certbot --nginx 로 발급)
  client_max_body_size 210m;          # APK 올리기(200MB) · 사진(8MB)
  location / {
    proxy_pass http://127.0.0.1:3071;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_read_timeout 90s;           # AI 답변 최대 60초
  }
}
server { listen 80; server_name bot.sellerbricks.co.kr; return 301 https://$host$request_uri; }
```
- 서버는 `trustProxy` 가 켜져 있어 HTTPS 쿠키(Secure)가 자동 적용된다.
- `/admin` 을 사무실 IP 로만 열고 싶으면 `location /admin { allow …; deny all; proxy_pass …; }` 추가.

## 4. 백업
- SQLite: `data/bot.db` 를 하루 1번 복사 (예: `sqlite3 data/bot.db ".backup data/backup/bot-$(date +%F).db"`)
- `data/app-secret.txt`(APP_SECRET 을 .env 에 안 넣은 경우), `data/apk/` 도 함께

## 5. 자동 작업 (서버 안에서 돎)
| 작업 | 주기 |
|---|---|
| 알림 엔진 | 5분마다 (관리자 화면에서 켜야 동작) |
| 기록 정리 | 하루 1번 — 대화 로그·알림 90일(`LOG_RETENTION_DAYS`), 만료 결과물 7일, 사진 30일, 만료 세션 |

pm2 인스턴스는 **1개**로 운영 (알림 중복 방지, SQLite). 여러 대로 늘릴 때는 DB 를 PostgreSQL/MySQL 로 바꾸고 알림 엔진을 1대에서만 켠다.

## 6. 앱 푸시 (다음 단계)
웹·앱 사용자 알림은 지금 **알림함**(웹챗 종 아이콘)에 쌓인다. 휴대폰 푸시를 보내려면:
1. Firebase 프로젝트 생성 → 안드로이드 앱(`kr.co.sellerbricks.aibot`) 등록 → `google-services.json`
2. 앱에 `@capacitor/push-notifications` 추가, 서버에 FCM 서비스 계정 키
3. `src/notify/engine.ts` 에 FCM 발송 추가 (Notification 저장 시 함께 발송)

카카오 사용자 알림은 지금 "가짜 발송(기록만)". 알림톡 템플릿 심사 후 셀러브릭스 알림톡 모듈로 보내는 API 를 04 명세에 추가할 예정.
