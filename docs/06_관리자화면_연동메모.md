# 새 관리자 화면(public/admin.html · /assets) 연동 메모 — 2-1차

새 관리자 화면 `/admin`에서 테스트 채팅, FAQ 관리, 결과물 열람 기록을 사용할 수 있다.

## 서버 쪽 (이미 반영됨)
- `/admin` → `public/admin.html` (`{{PUBLIC_ORIGIN}}` 은 `PUBLIC_BASE_URL` 로 치환)
- `/admin/classic` → `public/admin-classic.html`
- `/assets/:file` → `public/:file` (css·js·svg·png·jpg·webp·ico 만, 하위 폴더·숨김 파일 차단)

## 관리자 화면 연동
| 기능 | API | 화면 |
|---|---|---|
| 테스트 채팅 사진 첨부 | `POST /admin/api/chat` body 에 `image: { base64, contentType }` (8MB 이하) | 사진 첨부 버튼에서 파일 선택 |
| 사진 카드 | 응답 `reply.basicCard` = `{ imageUrl?, title, description, buttons: [{ label, action: 'message'\|'webLink', value }] }` | message 버튼은 value 를 다시 전송, webLink 는 새 창 |
| 결과물 링크 | 응답 `reply.link` = `{ label, url }` (리스트카드가 없을 때) | "결과물이 준비됐어요" 카드 + 버튼 |
| 숫자 검증 경고 | `reply.checkWarn` | 마지막 응답과 대화 로그에 표시 |
| 피드백 | `template.quickReplies`에 ‘도움 됨’, ‘아쉬워요’ 포함 | 선형 아이콘과 문구가 있는 바로가기 버튼 |
| 사용량 | `GET /admin/api/state` → `usage.feedbackUp / feedbackDown / numberWarnings`, `publicBaseUrl` | 대시보드 통계 |
| FAQ 관리 | `GET /admin/api/faq`, `POST /admin/api/faq`(id 있으면 수정), `DELETE /admin/api/faq/:id`(숨김), `POST /admin/api/faq/search` | 목록·편집·검색 시험 |
| 결과물 열람 기록 | `GET /admin/api/artifacts` | 표 (제목·사용자·열람 수·만료) |
| 로그 | `GET /admin/api/logs` 행에 `checkWarn`, `feedback` 추가 | 표시 |
| 도구 | `state.tools[].annotations.readOnlyHint` | 읽기/쓰기 표시 |

## 3차 추가 (2026-11-13) — `public/admin-ext.js`
새 화면에 메뉴 3개를 추가했다: **채널 · 앱**(`#channels`), **운영 · 알림**(`#ops`), **외부 AI(MCP)**(`#mcp`). 서비스 연결 카드에 스토리지 마켓 설정 폼(`#studioForm`), 테스트 채팅에 "답변 모양"(`#testView`) 추가.
- HTML: `public/admin.html` 의 해당 섹션, 동작: `public/admin-ext.js`(admin.js 의 `api`·`table`·`escapeHtml`·`feedback`·`icon` 사용), 스타일: `admin.css` 끝의 "채널·앱 / 운영·알림 / MCP" 블록
- admin.js 수정은 최소: 테스트 채팅 body 에 `view`, 샘플 셀러 목록에 스토리지 마켓 그룹(`data-platform="STUDIO"`), 연결 코드 발급에 `platform`
- 디자인을 고칠 때는 ID 를 유지하면 admin-ext.js 가 그대로 동작한다

| 기능 | API |
|---|---|
| 채널 | `GET/POST /admin/api/channels`, `POST /admin/api/channels/apk?version=&note=` (본문=APK 파일), `GET /admin/api/sessions`, `POST /admin/api/sessions/:id/revoke` |
| 운영 | `GET /admin/api/ops`, `POST /admin/api/ops/cleanup`, `GET /admin/api/quality?type=down\|warn\|error`, `POST /admin/api/cost`, `POST /admin/api/password`, `POST /admin/api/users/:id/block\|unblock` |
| 알림 | `GET/POST /admin/api/notify`, `POST /admin/api/notify/preview`, `POST /admin/api/notify/run` |
| MCP | `GET/POST /admin/api/mcp`, `POST /admin/api/mcp/tokens`, `POST /admin/api/mcp/tokens/:id/revoke` |
